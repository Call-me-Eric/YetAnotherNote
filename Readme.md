# YetAnotherPage

注：本软件仍在开发中，**不保证**功能完备性和稳定性。

## 引言

自从无纸化办公（学习）开始广泛传播，笔记软件的重要性不言而喻。

不过现有的笔记软件，要不然每年都要要花钱订阅，功能却少得可怜；要不然iOS平台独占，别的设备用不了；要不然同步做的不好，说不准哪天笔记丢失……

于是，基于 Flutter 实现的跨平台笔记 **YetAnotherPage**，问世了。

## 介绍

作为一款跨平台笔记，YetAnotherPage（以下简称YeP）可以在 macOS、iOS、Android、Windows、Linux 上用同一套界面打开，拥有相同的展现，就像 PDF 一样。

既然要支持多平台，我们注意到移动端（尤其是平板）和桌面端的笔记操作方式并不相同。移动端通常通过手写笔进行书写，而桌面端在编辑笔记时，更多的时候是通过打字。

于是我们同时支持手写和markdown编辑笔记，这样每一种设备都能够很有效的编辑笔记。注意，我们仍然保留了使用不适合自己平台特征的编辑方式，即便没有更多的支持。

截止本次提交，我们已经实现以下功能：

- **笔记库**：新建、打开、重命名、删除。库就是磁盘上的一个文件夹，没有另做一套虚拟目录。
- **页面**：多页纵向排在画布上；可以在当前页前或后插入一页（复制当时的图层结构，内容为空）；可以删除页，但至少留一页。
- **图层**：面板里从顶到底列出，可以隐藏、锁定、上移、下移。隐藏的层不画，锁定的层不接收新笔画。
- **手写**：钢笔笔画。手写笔有压感、方位角和高度角就用采样，没有就用固定值；鼠标也能画。手指不落笔，手指用来平移。
- **橡皮**：对象橡皮擦掉整条笔画；区域橡皮只擦掉经过的一段，一条笔画被切开后剩下几段就是几段。
- **撤销 / 重做**：线性。笔记内换页不清空；关掉笔记即清空，再次打开后旧操作不能再撤。
- **文字框**：Markdown 源码与渲染结果切换。标题、列表、强调、`$...$` 公式都会渲染。框可以移动、可以改大小，改宽度即重新换行，字号不缩放。
- **手写笔侧面按键**：iOS 上是 Apple Pencil Pro 捏笔。悬停处若有文字框就选中它，否则打开圆弧工具栏。
- **视图**：捏合缩放、单指平移（带惯性），进入笔记时自动居中第一页。

还没实现的：荧光笔、套索、图片、PDF 导入、导出副本、`.yep` 导入导出、嵌套文件夹、局域网同步。

## 环境配置

由于目前还在开发阶段，因此给出环境配置。


Flutter（stable 渠道，Dart SDK `^3.13.5`）。依赖只有 `path_provider` 和文字渲染用的 `markdown_widget`、`markdown`、`flutter_math_fork`。

```bash
flutter pub get
flutter run -d macos          # 也可以 windows / linux
flutter run -d <iOS 设备>
flutter run -d <Android 设备>
```

检查与测试：

```bash
flutter analyze
flutter test
```

## 操作手册

由于操作设备的多样性，我们不得不规范化各种操作。

### 移动端

我们定义以下基本操作。其余操作均基于这些基本操作。

#### 手指操作

指使用手指直接操作屏幕。

按照是否移动和按压时间分为

1. 短按：手指的移动距离不超过 10 point，并且手指在屏幕上停留不超过 380 ms 就离开屏幕的操作。
2. 长按：手指的移动距离不超过 10 point，并且手指在屏幕上停留超过 380 ms 就离开屏幕的操作。注意，如果在停留期间移动距离超过 10 point 就会变为拖拽状态
3. 拖拽：手指的移动距离超过 10 point

按照手指数目分为

1. 单指：通常指只有一个触摸点
2. 双指：通常指有且仅有两个触摸点
3. 三指：通常指有且仅有三个触摸点
4. 四指：通常指有且仅有四个触摸点

#### 手写笔操作

默认情况下，移动端想要通过书写方式，必须通过手写笔进行。用户可以自定义为手指也可以书写，不过这可能导致判定问题。

通常情况下，手写笔指能够通过笔尖与屏幕或感应板的接触，将用户的书写、绘画或点击动作转化为电子信号，从而实现类似纸笔书写的交互体验的一种设备。

通过**模拟手指操作**的触控笔会被视作**手指操作**。

手写笔拥有三种操作

1. 书写：通常指通过手写笔笔尖接触屏幕，并移动以进行此操作。
2. 侧键：**本功能需要设备硬件支持**，通过按下手写笔侧键（或者apple pencil捏一下）进行此操作。一般情况下，在手写笔可以代替手指的情况下，侧键可以代替**长按**
3. 悬停：**本功能需要设备硬件支持**，通过将手写笔笔尖悬浮在屏幕上方一段距离（**但不接触屏幕**）进行此操作。

### 功能

#### 主界面

在主界面下，**手写笔操作会被视作手指操作**，即将手写笔视作一根特殊（拥有侧键）的手指，并符合手指操作的各种特性。

用户可以通过点击右下角“+”新建一个笔记。

用户可以通过右上角的设置按钮进入设置。

用户可以通过点击一份笔记，来查看和编辑这份笔记。这将进入笔记页面。

用户可以通过长按一份笔记，来打开关于一份笔记的菜单。目前只有“删除”和“重命名”，后续功能有待更新。

通过将手写笔悬停在某一份笔记上，并按下侧键，同样可以打开菜单。

#### 笔记页面

在笔记页面下，手写笔操作与手指操作会严格分开。

底栏从左到右是钢笔、文字、对象橡皮、区域橡皮、撤销、重做、缩小、放大、插入页面、删除此页、图层。标题栏右侧是重命名、删除这份笔记，以及设置。

- 单指拖动平移，双指通过捏合进行缩放。双指拖动仍旧会进行平移，但不会触发“惯性”。
- 用手写笔在页面上可以进行编辑操作。悬停时会显示笔尖：钢笔是小点，橡皮是圆圈。
- 「图层」打开右侧抽屉，这一页的图层都在那儿，最上面的层盖住下面的层。
- 再次点击钢笔工具，工具栏上方出现一条长条。再点一次钢笔则隐藏。从左到右是尺寸、颜色、虚实的预设，每一类之间用一条竖线分开。放不下可以滑动。尺寸显示成一条该粗细的线，线上面写着数值。
- 通过侧键打开快捷切换工具后，长按（侧键）钢笔工具，会套一个更大的圆弧在快捷工具栏外面，圆心与快捷工具栏相同。上面同样是这些预设。放不下可以滑动。

#### 工具栏

编辑一份笔记，总是需要好的工具。接下来介绍我们实现的工具。

部分使用工具的情况，**手写笔操作会视作手指操作**。

##### 书写

点击钢笔工具，用户通过操作手写笔书写可以写字。

进行书写时，**手写笔不可视作手指**。

再次点击钢笔工具，工具栏上方出现预设长条。再点一次则隐藏。短按一个预设就切换到它。长按一个预设，才打开这个预设的调整界面。

调整这些预设时，**手写笔视作手指操作**。侧键等于长按。

尺寸数量、颜色数量、虚实数量不在工具栏里改，到设置里改。

###### 尺寸

钢笔尺寸指的是画出的线的“宽度”。

用户可以通过手指**短按**已经存储的尺寸，来切换钢笔的尺寸。

默认情况下，用户可以存储3个尺寸，分别为1.5、3、6。

用户可以**通过设置修改**存储尺寸上限。新增的尺寸初始值均为**3**。

在预设里，一个尺寸显示为一条线，粗细就是这个尺寸，线的上面写着数值。

如果修改存储上限低于原有的，那么从末尾**删除**足够的尺寸数目，来满足新的存储上限。这些尺寸无法恢复。

用户可以通过手指**长按**已有的尺寸，呼出调整界面来修改这个尺寸。

尺寸调整界面包括如下内容：

1. 滑动条：位于调整界面下面，占据界面下方（下方右侧留给数值调整），用于调整笔的粗细
2. 数值调整：位于滑动条右侧，与滑动条同步，允许用户通过直接调整数值来跳调整笔的粗细。
3. 示例面板：占据调整界面上方，内容为一条直线，用于体现这个尺寸设置的效果。

用户的修改即刻生效，即修改尺寸后会直接保存在选择的槽位。

###### 颜色

钢笔颜色指的是画出的线使用的颜色。默认存储一些常用的颜色，比如黑色、白色、红色、蓝色、黄色。

用户可以通过手指**短按**已经存储的颜色，来切换钢笔写出的颜色。

默认情况下，用户可以存储5个颜色，分别是黑色、白色、红色、蓝色、黄色。

用户可以**通过设置修改**存储颜色上限。新增的颜色初始值均为**白色**。

如果修改存储上限低于原有的，那么从末尾**删除**足够的颜色数目，来满足新的存储上限。这些颜色无法恢复。

用户可以通过手指**长按**已有的颜色，呼出调色板来修改这个颜色。

调色板界面就类似于ps的调色板，上面是一个可以切换RGB和HSV的标准调色板，下面放着一些常用的颜色（不是用户自定义的）点击即可调整上方标准调色板为此颜色。再下方一个错号和一个对号，如果用户点击错号则不保存，否则保存。

###### 实线与虚线

用户可以通过调整一条线的**循环长度**和**虚实占比**来调整一条线的虚线程度。

用户可以通过手指**短按**已经存储的虚实线，来切换钢笔写出的虚实线。

默认情况下，用户可以存储1个虚实线，为**纯实线**。

用户可以**通过设置修改**存储虚实线数目上限。新增的虚实线初始值均为**纯实线**。

如果修改存储上限低于原有的，那么从末尾**删除**足够的虚实线数目，来满足新的存储上限。这些虚实线无法恢复。

用户可以通过手指**长按**已有的虚实线，呼出调色板来修改这个虚实线。

类似于尺寸调整界面，不过这次同时拥有两个滑动条，上下排列。

##### 文字

在空白处使用手指**长按**，再往右下**拖动**，调整文字框直到用户希望的大小，并且框由半透明变成不透明，松手，即可生成一个文字框。

###### 焦点与失焦

初始状态下，每一个文字框都处于**失焦**状态。当用户使用手指**短按**一个文字框后，此文字框获得**焦点**。当用户点击非此文字框的其他笔记位置，或者切换工具，将使已经获得焦点的文字框失焦。

###### markdown渲染

当一个文字框获得焦点后

点已有文字框会进入编辑，将会显示 Markdown 源码；点别处失焦后渲染。

长按已有文字框选中它，可以拖动框体移动，拖右下角的方块改大小，框旁边出现「编辑」和「删除」。删除会进撤销栈。
